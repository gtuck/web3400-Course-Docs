# Project 03 Starter - MVC with Router

1. Copy this starter into your repo at `projects/03/`
2. From `projects/03/`, run `composer dump-autoload`
3. Ensure your database is running and the `posts` table exists (from Project 01/02)
4. Start the dev server from `projects/03/`: `php -S 0.0.0.0:8000 -t public`
5. Visit http://localhost:8000 - you should see the blog post list rendered through the front controller
